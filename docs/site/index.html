Operator gates

  • Use digest-pinned images for production.
  • Use the negotiated PostgreSQL schema from the current owner capability manifest and transactional fencing for hosted authority.
  • Bind indexer/reconciler leases to the active coordinator epoch and roll them after promotion.
  • Keep every service command absent from the current owner capability manifest disabled.
  • Supply TLS, independently operated RPC endpoints, and managed secrets.
  • Run smoke, soak, backup/restore, and evidence collection before traffic.
